Sales Analytics Dashboard

Construire un système permettant à une entreprise de suivre ses ventes et de répondre à des questions comme :

Combien avons-nous vendu ?
Quel est notre profit ?
Quels produits se vendent le mieux ?
Quelle région génère le plus de revenus ?
Comment évoluent les ventes dans le temps ?
Quels clients sont les plus importants ?
Quelle catégorie est la plus rentable ?


Dataset : 

| Column         | Description          |
| -------------- | -------------------- |
| Order_ID       | Identifiant commande |
| Order_Date     | Date                 |
| Customer_ID    | Client               |
| Customer_Name  | Nom client           |
| Country        | Pays                 |
| Region         | Région               |
| Category       | Catégorie            |
| Product        | Produit              |
| Quantity       | Quantité             |
| Unit_Price     | Prix unitaire        |
| Discount       | Remise               |
| Sales          | Chiffre d'affaires   |
| Cost           | Coût                 |
| Profit         | Profit               |
| Payment_Method | Moyen de paiement    |
